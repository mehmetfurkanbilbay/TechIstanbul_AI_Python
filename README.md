# AI LEARNING - E-posta Spam Tahmini

- Bu proje console üzerinden eğitim amaçlı bir Classification uygulamasıdır.

---

## Github Link
[Github](https://github.com/hamitmizrak/TechIstanbul_AI_Python)


### Requirements.txt yukle 
```shell
py -m pip install -r requirements.txt
py eposta_spam.py
```



### CSV Örnek Sütunları
```shell
-kelime_sayisi
-link_sayisi
-buyuk_harf_orani
-supheli_kelime_sayisi
-gonderici_puani
-ek_var
-spam
```
`spam`:0 =normal, 1=spam
---

### Örnek console üzerinden çözüm sırası
STEP-1
1. CSV dosyasını seç/yükle 
    > 1a.Manuel yaz 2a.Dinamik seçsin

STEP-2
2. Veri temizle & kaydet
3. Veriyi önizle
4. Veri kalitesi analizi
5. Doğal veriyi tekrar yükle

STEP-3
6. Model eğit
   > Logistic Regression, Decision Tree, Random Forest

7. Model Sonuçları Karşılaştır
8. Classification Report - PDF, txt olarak kaydet
9. Confusion Matrix
10. Yeni bir e-posta için tahmin 
0. Çıkış
